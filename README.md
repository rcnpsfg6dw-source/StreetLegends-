# STREET LEGENDS
Gra samochodowa 3D w przeglądarce (three.js). Wyścigi, Time Attack, Dziki Zachód (Free Roam), garaż, tuning, paliwo, drive-thru, bank, pociągi.
Sterowanie: strzałki/WASD, E/Q biegi, Spacja hamulec ręczny, C kamera, F akcja, R reset, Esc menu, G auto-biegi. Na telefonie przyciski ekranowe, tryb poziomy.
Uruchomienie: otwórz index.html (wymaga internetu - three.js z CDN).
